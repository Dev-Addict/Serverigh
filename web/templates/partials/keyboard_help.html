Keyboard Shortcuts

Navigation

/
Focus search.
Esc
Leave search or close a modal.
j
Move down one row.
<count>j
Move down count rows.
k
Move up one row.
<count>k
Move up count rows.
gg
Jump to the first row.
G
Jump to the last row.
h
Go to the parent directory.
<count>h
Go up count directories.
l
Open a folder or preview a file.
Enter
Open the selected row.
o
Open the selected row.
b
Use browser/back breadcrumb behavior.

Actions

r
Refresh the current listing.
R
Refresh the current listing.
yy
Copy the selected relative path.
Y
Copy the selected absolute path.
f
Focus the files pane.
p
Focus the preview pane.
?
Open this help modal.

Write Mode

a
Create a folder in write mode.
cw
Rename the selected row in write mode.
cp
Copy the selected row in write mode.
mm
Move the selected row in write mode.
dd
Move the selected row to trash in write mode.
